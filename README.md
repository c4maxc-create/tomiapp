# TOMI — Flutter preview 0.1

Arabic, right-to-left mobile UI preview for the new TOMI application. Dark navy
surfaces, violet accents, and five persistent bottom navigation destinations:
Home, Chats, Voice Rooms, Games, and Profile.

**This is source code, not an APK.** The Android APK is produced by the included
Codemagic workflow after these files are committed to the repository.

See [START_HERE_AR.md](START_HERE_AR.md) for browser-only setup instructions.

## Available demo interactions

- Text posts and text stories, likes, comments, saved-post toggle, follow toggle.
- Local private/group chat previews, username search, unread badges.
- Voice room seat layout, local room chat, microphone button UI preview.
- Voice/video call UI previews; no camera or microphone capture occurs.
- Profile editing with username validation.
- Separate demo coin balance, charisma, XP, and account level.
- Demo self-gifts increase charisma; other-recipient gifts simulate sending only.
- A four-question single-player quiz awards demo XP.
- Games catalog cards for Tomiro, Domino, and Snakes & Ladders.

## Scope

All people, posts, follower counts, coins, and room occupancy are sample data.
Changes exist only in memory during the current process session and reset when
the app process is killed. Navigation preserves state within that session.

There is no backend, real login, media picker/upload, real video playback,
push notification delivery, live audio/video, purchase processing, or multiplayer
engine in this preview. The landscape artwork is generated by Flutter's canvas,
and the video tile is a design placeholder. Cocos integration is a later,
separate implementation task; the quiz here uses ordinary Flutter widgets.

## Cloud build

The root `codemagic.yaml` defines **TOMI Android Preview** on `mac_mini_m2`,
Flutter stable, and Java 17. Choose this YAML workflow instead of the existing
Workflow Editor's `Default Workflow`.

Build steps:

1. `tool/bootstrap_android.sh` uses the installed Flutter SDK to generate the
   Android/Gradle scaffold while preserving application source and custom tests.
2. `tool/configure_android.py` sets the app name to TOMI and adds a vector icon.
3. `flutter pub get`, `flutter analyze`, and `flutter test` run.
4. `flutter build apk --debug` produces the preview.

Downloadable artifact: `TOMI-preview-0.1.apk`.

No purchase or deployment to an app store is configured. This workflow creates
a debug build for design testing. Production signing and persistent signing
credentials need a separate configuration before public distribution.

The archive deliberately omits generated Android toolchain files, which are
generated by Codemagic's installed Flutter SDK. A plain Workflow Editor build
will need the bootstrap script as a pre-build step; use the included YAML
workflow for this package.

## Development with an installed Flutter SDK (optional)

```sh
bash tool/bootstrap_android.sh
flutter pub get
flutter analyze
flutter test
flutter run
```

The browser upload and Codemagic build do not require installing Flutter on the
user's computer.

## Validation status

The package configuration and Android bootstrap preservation have been checked
locally. The source includes widget tests for compact and landscape screens,
larger text, text publishing, and chat sending, plus state tests for likes and
separate demo balances. Flutter/Dart compilation, these Flutter tests, and APK
generation have **not** run in the authoring environment, which has no Flutter
or Android SDK. They run in the Codemagic workflow; use its logs to resolve any
build failures before treating the APK as tested.
