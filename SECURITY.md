# TOMI security

Report suspected vulnerabilities through GitHub private vulnerability reporting (Security → Report a vulnerability), if enabled by the repository owner. Do not post credentials, private messages, user media, or exploit details in public issues. If private reporting is unavailable, ask the owner for a private reporting channel before sharing sensitive details.

Please include the affected release, reproduction on accounts you own, expected and actual behavior, and impact. Test only your own local environment and data. Production load testing and access to other users' data require explicit authorization.

Supported code is the latest main release. Dependency advisories, regression tests and code review reduce risk; they do not constitute a penetration-test certification. See `ops/SECURITY-OPERATIONS.md` for activation, recovery and incident handling.
