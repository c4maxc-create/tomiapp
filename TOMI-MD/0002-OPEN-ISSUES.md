# المتبقي — نطاق التطوير دون الألعاب

## بوابات عاجلة قبل ميزات جديدة
1. تشغيل workflow حديث على main للتحقق من API + SQLite + PostgreSQL + restore، وFlutter analyze/tests + Android APK بعد تعديل روابط الرسائل.
2. اختبار فتح روابط YouTube وغيرها على Android، الروابط العادية وwww، علامات الترقيم، الرسائل الطويلة، الروابط غير الصالحة، وإعادة بناء الرسائل أثناء التمرير.
3. تجربة حسابين وهاتفين: إرسال/استلام/تحديث المحادثة، الصوت والصور والفيديو، إعادة الاتصال، الإشعارات، الغرف والمكالمات.
4. نشر Render فقط بعد مراجعة التغييرات واتباع دليل النشر الحالي؛ لا يوجد نشر إنتاجي مثبت هنا.
5. تنفيذ اختبار أداء واقعي وتحديد حدود قابلة للقياس قبل أي قرار توسع أو إدخال Redis/Go/Rust إضافي.

## مراحل غير الألعاب المعتمدة
- المحادثات: تحسين معاينة الروابط، البحث، الرد والتفاعلات والتثبيت، إدارة الوسائط والرسائل.
- الثبات: R2 multipart/resume، الفيديو والتحويل، WebSocket وإعادة الاتصال، الإشعارات، الكاش والذاكرة.
- الأمان: MFA والجلسات، الصلاحيات الخادمية، رفع الملفات وفحصها، الأسرار والنسخ الاحتياطي والتدقيق.
- تجربة المجتمع: المنشورات والقصص والتعليقات والبلاغات، الغرف والمكالمات، الملف الشخصي والإدارة.
- الأداء والتسليم: اختبارات تكامل وحمل، مراقبة، أرشيف كامل وتقرير حدود التحقق.

## الاعتماديات الخارجية
FCM/Firebase وLiveKit وR2/Cloudflare وRender ومفاتيح الإنتاج تحتاج إعداد المالك. بوابة الدفع غير محددة، لذلك لا شراء نقدي حقيقي. WAF الكامل والفحص الأمني المستقل وتجربة الأجهزة الفعلية واختبار 1000 مستخدم لا تعتبر مكتملة دون دليل.

## الألعاب
مؤجلة بالكامل بطلب المستخدم. لا تعديل ملفات/واجهات/محركات الألعاب أو XP/الروليت أو أنظمة تقدم الألعاب في مراحل هذه الخطة.


## خطة التنفيذ التفصيلية
القائمة النشطة ذات الأولويات ومعايير الإكمال موجودة في `TOMI-MD/0046-NON-GAMES-REMAINING-EXECUTION.md`. استخدمها لتحديث هذا الملف مع كل مرحلة، ولا تعتبر اختبار CI بديلًا عن اختبار R2/FCM/LiveKit أو الهاتفين. الألعاب خارج النطاق.
