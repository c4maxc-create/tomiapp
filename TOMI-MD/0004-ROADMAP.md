# خطة TOMI المعتمدة — دون مرحلة الألعاب

اعتمد المستخدم تنفيذ جميع مراحل التطوير السابقة باستثناء مرحلة الألعاب. الألعاب الموجودة محفوظة كما هي ومجمدة مؤقتاً.

## حالة التنفيذ في 13 نوفمبر 2026
اجتازت مراحل التطوير والتحقق الآلي غير المتعلقة بالألعاب بوابات Flutter/Android، تكامل Flutter مع API Node المعزول، API على SQLite وPostgreSQL 17، encrypted backup/restore، وفحوص الأمان. راجع سجل الأدلة والـ commits في `TOMI-MD/0046-NON-GAMES-REMAINING-EXECUTION.md`.

## ما تبقى قبل الإطلاق
1. اختبار R2/Cloudflare الحقيقي في staging.
2. اختبار FCM/Firebase وLiveKit ومشاركة الشاشة على جهازين حقيقيين.
3. قبول غرف الصوت والهدايا والإشعارات والخلفية على أجهزة فعلية.
4. اختبار الفيديو والوسائط واستهلاك الذاكرة على أجهزة وشبكات مختلفة.
5. اختبار حمل staging وقياس الموارد قبل اعتماد أي هدف توسع.
6. مراجعة المراقبة والتنبيهات والنشر على Render بموافقة المالك.
7. تجربة استعادة ملفات R2 الفعلية.
8. إصدار APK release موقّع بعد الاختبارات الخارجية؛ APK الحالي debug smoke فقط.

## قواعد لا تتغير
- لا نعدل الألعاب ولا نضيف ألعاباً جديدة في هذا النطاق.
- لا تغيّر قاعدة الإنتاج أو معرف المالك أو الأسرار أو إعدادات Firebase/MFA/R2/LiveKit دون إجراء آمن معتمد.
- لا تدّع نشرًا أو اختبارًا على هاتف أو حملًا إنتاجيًا دون نتيجة قابلة للتحقق.
- لا تضف بوابة دفع أو شحن حقيقي دون تحديد مزود الدفع وإعداداته.
- لا تضف TypeScript/Redis/Go/Rust لمجرد الاقتراح؛ القرار تابع لقياس حاجة فعلية.
- كل مرحلة تنتهي بتقرير تغييرات واختبارات وحدود، ثم أرشفة المصدر.
