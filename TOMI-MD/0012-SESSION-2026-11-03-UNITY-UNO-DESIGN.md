# جلسة 0012 — نموذج تصميم أونو Unity/C#

3 نوفمبر 2026، بغداد. طلب المستخدم بدء تصميم أونو بعد اختيار Unity/C# لطاولة وحركة أكثر احترافية مستوحاة من المرجع. هذه مرحلة تصميم أولي وليست تسليم لعبة Unity متصلة بالإنتاج.

## المنجز

مشروع مستقل unity/TomiUno مثبت على Unity 6 LTS 6000.0.62f1 مع مصدر C# ومولد مشهد وأصول إجرائية وملفات meta ثابتة. طاولة مجسمة وحافة ذهبية، توزيع متتابع للمقاعد الأربعة، اختيار ورفع ولعب وسحب الورقة، ترتيب اليد، مؤثرات العكس والتخطي و+2 و+4 واختيار اللون وUNO وتقليل الحركة.

DTO وSnapshotGate لاستقبال حالة خادمية مستقبلًا، ومنع الردود المكررة والقديمة وخلط المباريات. ActionRequested بوابة أولية وليست عميل HTTP أو جسر Flutter جاهزًا. حفظ الإيصالات الدائم وربط الجلسة والتحقق من الاستجابة لاحقًا.

معاينة بصرية تفاعلية بالعربية في design/uno-preview. هذه معاينة متصفح وليست لقطة Unity أو Flutter، ولا ادعاء بتطابق المحركين بالبكسل. standalone.html يجمع CSS وJavaScript بدون تبعيات أو شبكة ويفتح من القرص. README لكل جزء وخمسة اختبارات EditMode للبوابة.

## التحقق الفعلي وحدوده

- اختبارا Node لمنطق المعاينة نجحا: منع السحب غير المحدود وتكرار المعرفات واللعب بدون اختيار ولون wild غير صالح.
- Chromium/Playwright: اختيار ولعب وسحب وwild وإعادة توزيع بتقليل الحركة، بعروض1440 و390 و320، بدون خطأ JavaScript أو فيض أفقي بالصفحة.
- ملف standalone اختبر عبر HTTP محلي مع سبع أوراق وبدون أخطاء JavaScript؛ صور سطح المكتب والموبايل محفوظة. فتح file:// المباشر منعه متصفح البيئة المُدار ولم يختبر؛ الملف مستقل ومهيأ للفتح المباشر بمتصفح عادي.
- Unity Editor غير مثبت؛ C# وEditMode وPlayMode وبناء Unity APK لم تنفذ. لا تعتبر المعاينة نجاح Unity أو قياس FPS.

## الحدود والخطوة التالية

اللعب الموجود Flutter والخادم وقواعد الأونو والرصيد والكارزما والـXP بلا تغيير. النموذج يستخدم أوراقًا وأسماء ومؤقتًا تجريبيًا ولا يتصل بالإنتاج. لا أسرار أو أصول مدفوعة أو مكتبة دمج Unity أضيفت. لا GitHub push أو نشر خارجي بهذه الجلسة.

التالي مراجعة التصميم مع المستخدم، فتح المشروع بـUnity واختبار تجميعه والحركات، تطوير مشهد Unity لجودة المعاينة، ثم جسر دمج Flutter موثوق وتعريب وتزامن حالات الخادم واختبار الصوت والأداء على هاتفين. يراعى بقاء صوت الغرفة واستعادة اتجاه الشاشة. نتيجة بناء APK لتصحيح CI52 بعد commit48f6192 تبقى تحتاج دليلًا حديثًا.
