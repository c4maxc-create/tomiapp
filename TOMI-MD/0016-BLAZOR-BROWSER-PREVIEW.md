# 4 نوفمبر 2026 — معاينة C# بالمتصفح

اختار المستخدم Blazor صراحة بعد توضيح أنه يختلف عن Unity. أُنشئ مشروع previews/Tomi.BlazorPreview بمعاينات محلية للألعاب الخمس ومشروع اختبارات C#. لم تُعدّل Unity أو Flutter أو الخادم.

نجح البناء والنشر المحلي واختبارات النماذج السبعة، وفحوص Chromium للألعاب الخمس عند ثلاثة أحجام شاشة. الأدلة في validation/blazor-preview والتعليمات في previews/README-AR.md. هذه معاينات تفاعل وليست ألعابًا جماعية مكتملة.

لا يوجد رابط عام متحقق منه. api.github.com محجوب بسياسة الشبكة (403). حُفظت إضافة النطاق إلى مسودة البيئة مع الحفاظ على storage.googleapis.com؛ لم تُنشر المسودة. لا تعِد تغييرات الإعدادات السابقة. عمل Git لا يثبت توفر وصول API.

workflow باسم TOMI CSharp browser preview يدوي. deploy غير مفعّل افتراضيًا ويستبدل موقع Pages إن وجد. افحص الموقع الحالي والصلاحيات قبل النشر. يجب إعداد Settings → Pages → GitHub Actions، ثم قراءة الرابط من نتيجة نشر ناجحة. المستودع خاص؛ لا تجعله عامًا لتجاوز قيود الخطة. لا تقدّم localhost كرابط يمكن للمستخدم فتحه من جهازه.
