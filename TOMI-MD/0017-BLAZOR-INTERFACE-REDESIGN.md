# إعادة تصميم واجهة المعاينة — 4 نوفمبر 2026

طلب المستخدم مراجعة الواجهة والتنقل والشكل ودقة الرسومات. أُعيد تصميم Blazor بمجموعة ألعاب مرئية بالكامل على الهاتف، ورسومات SVG أصلية مميزة لكل لعبة، ومقدمة مرسومة، ومسار تنقل وزر تركيز يخفي المجموعة دون إعادة إنشاء حالة اللعبة. أضيفت رسومات SVG لتسعة أنواع من قطع الجمل وتفاصيل لسلالم وأفاعي اللوحة، وتحسينات CSS للأوراق والأحجار والطاولات.

المصدر في previews/Tomi.BlazorPreview، مع فحوص المتصفح في previews/check_browser.py. هذه معاينة C#/Blazor محلية؛ لا تغيّر Flutter أو Unity أو الخلفية أو قواعد اللعب الجماعي. الاستضافة العامة لم تُتحقق؛ الحزمة المبنية في previews/downloads قابلة للتنزيل من GitHub مع تسجيل الدخول للمستودع الخاص، ثم رفع مجلدها إلى استضافة ثابتة.
