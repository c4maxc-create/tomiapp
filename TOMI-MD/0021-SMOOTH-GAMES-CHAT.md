# 5 نوفمبر 2026 — سلاسة الألعاب والمحادثات، البناء 28

واجهة اللعب الفعلية C#/Blazor داخل مضيف Android/Flutter، والخادم Node.js. هذه تعديلات التطبيق وليست استبدالًا بـ Unity.

## الألعاب

لكل لعبة صفحة مستقلة: كمبيوتر، البحث عن لاعبين فعليين لنفس اللعبة، وطاولة خاصة بكود ودعوة من محادثة. البحث محفوظ بقاعدة البيانات، متسلسل ضد الطلبات المتزامنة، يستثني الحظر والمباريات الخاصة والحسابات غير المتاحة، وتجدد جلسة الانتظار أثناء الاستخدام. جاكارو تكمل المقاعد اللازمة بالكمبيوتر؛ لا ندّعي أن جميع المقاعد بشر.

حركات العرض تتبع سجل أحداث خادمي مرقّم: توزيع وطيران أوراق أونو، خطوات النرد ثم انتقال السلم/الأفعى، حركة قطع جاكارو واختيارها، ونقل قطع الجمل وتجميعها. تمنع الواجهة إدخال حركة ثانية أثناء تشغيل الحركة الحالية، وتتصالح مع أحدث نتيجة خادمية بعد العرض. الإعدادات مخفية خلف زر التحكم لتوسيع الطاولة على الهاتف.

أضيفت روليت مجانية بالنقاط لخيارات الكمبيوتر والبحث والطاولات الخاصة. لا تخصم أو تمنح كوينز. الروليت العامة الحالية بالكوينز تبقى خيارًا منفصلًا مع تأكيد الرهان وسياسة الرصيد الأصلية.

## المحادثات

إيقاف إعادة تحميل صندوق المحادثات بسبب أحداث الألعاب والغرف. بث الرسالة الجديدة كاملة عبر WebSocket مع حماية بيانات المرسل والانضمام المتأخر للمجموعة؛ عرض مباشر مع استكمال فجوات التسلسل، وإعادة اتصال ومزامنة احتياطية. للتعديلات والتفاعلات تحديث الرسالة المطلوبة بدل كامل السجل. يمكن للنص والملصقات التقدم بينما رفع مرفق واحد مستمر. بقيت معرفات الطلبات وإعادة المحاولة والتخزين الخاص بالحساب.

خفض إعادة كتابة الوسائط وفحص تنظيف الملفات أثناء الكتابة. إضافة ثلاثة ملصقات GIF أصلية متحركة، ورفع GIF محفوظ كما هو حتى 10MB. لا يوجد بحث Giphy أو خدمة خارجية جديدة. وضع تقليل الحركة يعرض بديلًا ثابتًا.

عُطل JIT لاتصالات PostgreSQL الخاصة بالخدمة: أظهر قياس محلي لاستعلام الملف الشخصي نحو 1141ms مع JIT مقابل 0.226ms بدونه، بعد التخطيط. هذه نتيجة استعلام محلي وليست ضمان زمن وصول الإنتاج. لا تغيير لحدود قاعدة البيانات أو TLS.
