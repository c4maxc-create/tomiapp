# TypeScript ولوحة المتابعة

يتطلب الخادم Node24. خدمات التجربة الجديدة `.mts` تعمل مباشرة دون مترجم في الإنتاج. تثبيت التطوير ثم الفحص:

```sh
npm ci
npm run typecheck
npm run build:admin
npm test
```

بعد تعديل `admin/dashboard.ts` أعد بناء `public/admin/dashboard.js` وأضفه إلى commit. يفحص `npm test` تطابق الملف المولد. لا يحتاج الإنتاج TypeScript ضمن اعتماداته التشغيلية؛ ملف JavaScript الناتج متتبع.

بعد نشر الخادم افتح `/admin` وسجل الدخول بحساب إدارة قائم. اللوحة للمتابعة والتقارير فقط؛ إجراءات الإشراف الكاملة في التطبيق. الرمز يبقى في الذاكرة، وصلاحيات الخادم هي المرجع. لا تضع مفاتيح أو حسابات تجريبية في ملفات النشر.
