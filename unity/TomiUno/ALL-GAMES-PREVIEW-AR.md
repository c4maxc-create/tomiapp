# معاينات الألعاب الخمس داخل Unity/C#

هذه حزمة معاينات محلية داخل Unity نفسه. لا Blazor أو HTML بديلًا عن المحرك. لم يتم تشغيل أو تجميع هذه الإضافة في البيئة الحالية لأن Unity Editor غير مثبت؛ملفاتها جاهزة للمراجعة والفحص داخل المحرك،ولا نعتبرها build تفاعليًا ناجحًا قبل ذلك.

## التشغيل الفعلي على جهاز فيه Unity

1. من Unity Hub ثبّت Unity6LTS6000.0.62f1 وفعّل رخصتك بالطريقة الرسمية. أضف WebGL Build Support إذا تريد معاينة بالمتصفح. لا ترسل بيانات دخول أو رخصة في المحادثة.
2. افتح المجلد unity/TomiUno كمشروع،وانتظر استيراد UGUI والتبعيات الموجودة.
3. اختر TOMI → Open all-games preview،ثم Play. أول تشغيل ينشئ مشهد Assets/Scenes/TomiAllGamesPreview.unity. المشهد المحفوظ سابقًا لا يستبدل تلقائيًا.
4. تظهر قائمة الأونو والسلم وجاكارو والجمل والروليت. زر ALL GAMES يرجع للقائمة،وزر REDUCE MOTION يقلل الحركة.

## ماذا يمكن تجربته؟

- الأونو:المشهد الثلاثي الذي صمم سابقًا،وتوزيع الأوراق والسحب والتحديد واللعب واختيار اللون وتقليب الوجه والظهر ومؤثرات الأوراق.
- السلم والأفعى:لوح100خانة،نرد تجريبي،حركة خانة بخانة،ومسارات صعود ونزول نموذجية،وإعادة البدء.
- جاكارو:لوح وأحجار واختيار حجر،ثم عينات حركةAوالرجوع4وتقسيم7والتبديل وK. هذه عينات حركة محلية،لا تطبيق كامل لقواعد المباراة أو الحماية والعضوية والفوز الجماعي.
- الجمل:لوح54قطعة بطبقات،اختيار المكشوف فقط،مطابقة3وخانة7،تراجع ونقل3وخلط ومخزن جانبي وإعادة البدء. هذه معاينة لوح واحد؛لا يوجد فريق متصل أو طلبات خادمية مشتركة بهذه المعاينة.
- الروليت:دوران وتباطؤ وقطاع توقف تجريبي. بدون رصيد أو رهان أو أرباح. ترتيب القطاعات والجوائز النهائي يعتمد على عقد السيرفر عند الدمج؛لا تستعمل المعاينة كتسوية مالية.

تستخدم الواجهة الإنجليزية مؤقتًا حتى إضافة تعريب Unity وتشكيل العربية والتحقق منه. الرسوم مولّدة داخل Unity/C#،وليست صورًا مرندرة من محرك آخر. لا نعرض لقطات متصفح كدليل على تشغيل Unity.

## تصدير معاينة Unity تعمل بالمتصفح

من المحرك اختر TOMI → Build all-games WebGL preview. بعد نجاح التصدير تكون النتيجة في Builds/WebGL. يستخدم التصدير ضغطًا معطلًا لتبسيط تقديم الملفات،ويعيد إعداد الضغط السابق بعد البناء. يولّد material مرجعيًا لتضمين Standard shader المستخدم في الجزيرة.

شغّل خادم ملفات HTTP من مجلد Builds/WebGL،وافتح المعاينة بالمتصفح. لا يكفي فتح index.html من القرص،ولا رفع ملف HTML وحده؛كل ملفات Build وTemplateData الناتجة مطلوبة.

للتصدير بالدفعات على جهاز يحتوي Unity المرخص وإضافة WebGL:

```text
Unity -batchmode -quit -projectPath <path-to-unity/TomiUno> -executeMethod BuildGamePreviews.WebGL -logFile <path-to-build.log>
```

## ما لم يتحقق بعد

المحرك غير متوفر في بيئة هذه المحادثة؛لذلك compilation وPlay Mode وWebGL ورندر الصور والأداء على الهاتف كلها غير منفذة. لا APK جديد بهذه الإضافة. مصدر Flutter والسيرفر الألعاب الحالي لم يستبدل بهذه المعاينات. ربط Unity بالجلسات والإيصالات والصوت واتجاه الشاشة وبناء التطبيق يتطلب مرحلة دمج وفحوص أجهزة بعد إثبات تشغيل المشاهد.
